<h1>Basic Requirements</h1>
install the packages from the requirement files first using python's pip
a MongoDB server is also in work for storing the data

For testing the pipeline, first install VSCode's extension, "Live Server" then host the "test_circular.html" using it.

To make sure you are able to use the database server, confirm that you have proper version of <b>MongoDB Compass</b> installed in your system.
After installing it, make a new connection and remember the client link (eg: <u>mongodb://localhost:27017/)</u>, it is mostly same for everyone so you wouldn't have to update it in the code.
Then make a new database named 'campus_chatbot_db' and within it make a collection named 'raw_documents', both of it can be easily.

To make the database -> press the '+' icon on the connection name and specify both the db and the connection.
<b>MAKE SURE TO WRITE THE EXACT NAME AS GIVEN HERE</b> otherwise you will have to alter the code here to run it.
